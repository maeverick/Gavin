# Gavin AI: Nigerian Law Study Companion

Gavin AI is an intelligent academic support system designed to improve how law students in Nigeria study, revise, and prepare for examinations.

## Project Structure

- `frontend/`: React-based frontend application.
- `backend/`: Node.js API layer.
- `ai-service/`: Python FastAPI service for RAG and embeddings.
- `docs/`: Documentation and legal source materials.

## Key Features

- **Conversational AI**: Context-aware learning assistance grounded in Nigerian legal materials.
- **Smart Notes**: Summaries, flashcards, and quizzes from uploaded materials.
- **Bar Exam Simulation**: Practice for Nigerian bar exams.
- **Study Planner**: Analytics and progress tracking.

## Tech Stack

- **Frontend**: React, Tailwind CSS.
- **Backend**: Node.js, Express.
- **AI Service**: Python, FastAPI, LangChain/LlamaIndex.
- **Database**: PostgreSQL + Vector DB.
